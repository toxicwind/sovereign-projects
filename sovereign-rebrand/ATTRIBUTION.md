# Safe Attribution Guide

## The Rule

Reference the parent as **historical fact**, not as **current branding**.

## ✅ Safe (Do This)

> "τ is a sovereign evolution of the agent framework space. We maintain sync capability with the original earendil-works/pi project — our common ancestor."

> "QED is a sovereign evolution of the editor space. We maintain sync capability with the original zed-industries/zed project — our common ancestor."

> "Herd is a sovereign evolution of the inference gateway space. We maintain sync capability with the original mostlygeek/llama-swap project — our common ancestor."

## ❌ Unsafe (Don't Do This)

> "τ is the new pi" — implies replacement, invites comparison lawsuit
> "QED is zed but better" — defamatory to original brand
> "Herd is llama-swap v2" — implies ownership of original brand
> "The official successor to pi" — false claim, trademark risk
> "Zed with AI" — co-opts Zed brand

## Why This Works

1. **"Common ancestor"** is biological terminology. It implies divergence, not replacement.
2. **"Sovereign evolution"** frames your work as independent adaptation, not derivative.
3. **"Maintain sync capability"** shows technical relationship, not brand relationship.
4. **"Original [project]"** is factual description, not trademark use.

## Legal Shield

- No trademarked terms in repo names (no "Pi", "Zed", "LLaMA")
- No trademarked terms in package names (npm/cargo/crate names should be tau/qed/herd)
- No co-branding (never "tau/pi", "qed-zed", "herd-llama")
- Factual statements only ("we started from" not "we own")
- License separation (upstream MIT, your SOL)
- Automated sync proves ongoing relationship, not abandonment

```markdown
- **Daily automated sync** via GitHub Actions

- **All upstream contributions** preserved and attributed
- **Upstream code** remains under its original [license] license

```

## If You Get a Takedown Notice

1. Verify the claim (is it actually trademark infringement or just competition?)
2. Check if your name is in a different class (software vs hardware, etc.)
3. Offer to add more prominent attribution (not rebrand)
4. If valid, rename is cheap — your code is what matters
5. Never ignore legal notices — respond promptly and professionally

## Bottom Line

You are not a fork. You are not a clone. You are a **sovereign evolution**.
The parent is your **common ancestor**. You diverged. You adapted. You improved.
That's how open source works. That's how science works. That's how life works.
